# Мифические войны v05.10 RC — исправления отображения карт в игре

## Почему возникла ошибка

В v05.9 редактор `v05-dynamic.html` использовал `v05-dynamic-core.js` + `v05-dynamic-manifest.js` и исходные файлы `v05/`, однако на поле боя, в начальной замене, в инспекторе и в 3D работал устаревший модуль `battle-card-renderer-v2.1C.js`. Поэтому при переходе между экранами карты изменяли оформление или оставались рубашками.

## Реализовано

- Общая презентационная точка входа `battle-v05-card-bridge.js`; применяет неизменённые оригинальные слои `v05/production/editor_manifest.json` и те же типы Creature/Spell/Weapon.
- Данные карты читаются по ID из нормализованного seed 162+7; стоимость, здоровье, атака и описание берутся из текущей модели игры. **Никаких обратных записей в игру или библиотеку.**
- Тестовый арт подбирается строго по ID; 99 из 169 доступны офлайн. У остальных 70 — подпись «АРТ В РАЗРАБОТКЕ», без чужой иллюстрации.
- Приоритет пользователя: локальный override (`card.artImage`/сохранённый проект) > IndexedDB редактора v05 > встроенный тестовый файл. Сохранённое кадрирование редактора применяется при наличии профиля.
- Светлый контрастный заголовок на цветной ленте и оптическое центрирование чисел (по измеренным границам текста) — в игре и новом редакторе.
- Начальная замена, 2D и 3D получают одну и ту же карту, с типовыми размерами для своих площадок; компактная версия также сделана из полноформатного v05 изображения.
- Непрерывная загрузка карт: сбой промиса не блокирует повторное создание видимой картинки. В 3D вместо рубашки собственной карты показывается временный подписанный фронт; после готовности заменяется v05 лицом.
- Предусмотрен безопасный fallback при повреждённых файлах; противнику рубашки по-прежнему положены по игровым правилам.

## Не трогали

- `battle-engine.js`, `deck-model.js`, `card-catalog.js`, `v05/production/editor_manifest.json`, утверждённые PNG, колоды и арт-источники.
- Google Sheets: **0 записей**. Авторизацию API не тестировали.
- 2D/3D игровые механики, поведение бота и правила замены не менялись.

## Результаты проверки

- Node 108/108.
- v05 слой/CSS/изображение: 10/10 изолированных Chromium-проверок, реальные PNG и WebP (без 1px-заглушек).
- Исходный редактор: 24/24 + 24/24 + 7/7 браузерных тестов.
- Настоящий клиентский `index.html` с полной JS-сборкой: запуск матча, mulligan с лицами, 2D-рука после подтверждения: 5/5.
- **Важно:** браузерная 3D-приёмка WebGL не завершена: Chromium в ограниченной среде завис при создании 3D-контекста. Браузерные 2D-тесты и статическая проверка 3D-ветки пройдены, но результат на Windows/опубликованном GitHub не подтверждён.

## Сборка и публикация

Публикация GitHub Pages: см. `GITHUB_FULL_DEPLOY_RU.md`. Патч Windows накладывается **поверх v05.9**, затем перезапуск локального сервера и `Ctrl+Shift+R`. Хранилища браузера связаны с конкретным origin — не сменяйте hostname/порт без резервной копии.
