# Полная Windows-версия v05.11 — как запустить

**Не патч.** Разархивируйте в новую папку на обычном локальном диске, сохранив вложенные каталоги `assets/`, `v05/`, `test-art/`, `arena-art/`, `server/`, `tools/`.

1. Запустите **`START_WINDOWS.cmd`**. Откроется PowerShell окно локального сервера и браузер `http://127.0.0.1:8765/index.html`. Консоль не закрывайте во время игры. Node и Python для офлайн-игры не нужны — сервер написан на PowerShell.
2. Переключитесь в игру/колоды/коллекцию. В коллекции редактор один — `v05-dynamic.html`.
3. Для отдельного запуска редактора закройте прежнее окно сервера и выполните `START_V05_EDITOR_WINDOWS.cmd` (тот же порт 8765).
4. Для Google Sheets нужен Node 20+, Google service-account JSON **за пределами этой папки**, права Sheets и переменные окружения. Используйте `START_V05_SYNC_WINDOWS.cmd` и подробное `README_V05_STAGE4_RU.md`. Запись по умолчанию выключена. **Не запускайте** обычный PowerShell-сервер и Sync-сервер одновременно на одном порту.
5. Если показываются устаревшие карты: `Ctrl+Shift+R`, убедиться что не запущена старая папка/другой сервер. Предпочитайте всегда адрес `127.0.0.1:8765`; `localhost` имеет иное хранилище.

## Проверка Hero HUD

Начать бой → подтвердить начальную замену → проверить героя, отдельные значения здоровья/брони, способность с маной и постоянно видимый слот оружия. Экипировать оружие, проверить атаку/прочность, уменьшить прочность до 1 в рамках разрешённых игровых действий. Включить 3D и проверить визуальное соответствие. После 3D вернуться в 2D, проверить сохранение партии.

**Открытые ограничения:** WebGL зависит от GPU, браузера/драйвера. Облачные тесты не подтвердили настоящий WebGL и не подтвердили Windows. Все исходные арты имеют тестовый статус.
