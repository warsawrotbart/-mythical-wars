v05 · только локально

Для CSV: экспортируйте листы с полным заголовком (21 столбец), кодировка UTF-8. Неполный набор ID нельзя применить.

Готово к проверке.

Арт, файлы изображений, маски, crop/pan/zoom и исходный манифест не импортируются. Данные игры, коллекции и колод не перезаписываются.

Предупреждения и ошибки
ПОДЭТАП 5 · GOOGLE SHEETS ЧЕРЕЗ ЗАЩИЩЁННЫЙ СЕРВЕР

Серверная синхронизация библиотеки

Сначала загрузка и сравнение; отправка на сервер только по отдельному подтверждению. Арт, маски, кадрирование, боевые колоды и production manifest никогда не синхронизируются.

v05 · по запросу

Для Windows откройте редактор через сервер на порту 8765. Для опубликованного сайта нужен собственный HTTPS backend; в GitHub Pages сервер не запускается.

Ключ остаётся только в поле до закрытия вкладки, не включается в HTML/архив/отчёт.

Ожидается подключение. Локальный редактор продолжает работать независимо.

Удалённая версия и журнал
Подключение не выполняется автоматически. После чтения сравнение поступающих данных появится выше, в панели импорта.

Сервер пока не опрошен.

При конфликте версий сервер отклонит запись (HTTP 409): обновите Google Sheets, перепроверьте diff. Защита оптимистическая: одновременное изменение таблицы непосредственно в Google во время записи не является атомарно блокируемым.
