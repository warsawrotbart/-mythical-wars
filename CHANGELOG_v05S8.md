# CHANGELOG v05.8 RC — встроенные тестовые арты

Дата: 10 ноября 2026. Основа: v2.1M.2 + v05.7 RC.

## Изменения

- Единственный редактор v05 использует **встроенную** библиотеку тестовых артов из `test-art/` без обращения к Google Drive. Арт подставляется строго по ID.
- Добавлен блок «Встроенный тестовый арт» с миниатюрой и явным статусом **«тестовый, не утверждён»**.
- Добавлена кнопка **«Вернуть встроенный арт»**: убирает пользовательскую замену только для текущего ID, обновляет локальный профиль/IndexedDB и не сбрасывает crop X/Y/zoom.
- Добавлен фильтр **«Только карты со встроенным артом»** в выборе 162 карт + 7 токенов, а также динамический счётчик покрытых записей.
- Для 77 записей без исходного файла не назначается чужой арт; токены по-прежнему отдельные и не получают неутверждённый PNG-шаблон.
- Исходный игровой каталог, боевые правила, колоды, геометрия/шаблоны, 88 графических ассетов v05 и исходные изображения не менялись.

## Объём встроенной библиотеки

- 92 из 169: CHR — 45, KNZ — 39, NEU — 8.
- Отсутствуют: 70 обычных карт и 7 токенов. См. `TEST_ART_COVERAGE_v05S7.md`.
- Оригинальные источники v05 для KNZ-019/006/014 имеют приоритет для этих контрольных карт.
- Каталог: `mw-test-art-catalog.js`; двоичные файлы `test-art/{ID}.webp`; SHA-256 и происхождение `test-art/test_art_inventory.json`.

## Важно

v05.8 RC — продолжение v05.7, не выпуск новых 77 изображений. Проверка реального Windows/IndexedDB, внешнего Google API и опубликованного GitHub Pages остаётся отдельной приёмкой. Перед публичной публикацией артов проверьте право на распространение.
