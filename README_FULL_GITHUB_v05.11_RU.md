# Полная GitHub Pages v05.11 — установка

**Не патч.** Архив включает полный статический сайт, не Node-сервер.

1. Распаковать ZIP. Содержимое папки **`mythical-wars/`** (не саму внешнюю папку) перенести в корень репозитория. Не потерять скрытую `.github/` и `.nojekyll`.
2. На GitHub открыть **Settings → Pages → Build and deployment**, выбрать **GitHub Actions**.
3. В **Actions** запустить `Publish Mythical Wars to GitHub Pages` вручную. Скрипт `tools/check_static_site.py` проверяет ссылки/ассеты/манифест, `tools/build_pages.py` собирает `_site`, workflow публикует сайт.
4. Открыть опубликованную страницу и проверить `index.html`, `v05-dynamic.html`, боевой 2D и 3D. После обновления — `Ctrl+Shift+R`. Изображения и JS должны отдаваться с HTTP 200.
5. Онлайн Google Sheets через публичный статический GitHub Pages **не работает** без отдельно размещённого защищённого backend. Никогда не загружать туда service-account JSON.

**QA приёмки:** оба героя в 2D/3D, доступность способности, 0 маны, использованная способность, пустой/занятый слот оружия, снаряжение с низкой прочностью, начальная замена, автосохранение и переключение 2D/3D. Настоящий 3D WebGL на опубликованном сайте остаётся обязательной проверкой перед stable.
