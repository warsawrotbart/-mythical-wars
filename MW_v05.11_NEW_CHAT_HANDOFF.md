# Мифические войны — стартовый документ для нового чата

**Версия:** `v2.1M.2 + v05.11 Hero HUD RC`  
**Дата:** 11.11.2026  
**Тип передачи:** полный контекст разработки (Windows + GitHub Pages), запуск с нуля **без патчей**.  
**Статус:** release candidate, не подтверждённый stable (не завершены реальный 3D WebGL/Windows/Pages E2E).

## 1. Главное, что нужно знать

Проект — коллекционная карточная игра «Мифические войны» в славянском фэнтези с белорусскими названиями, 2D-битвой и экспериментальной 3D-ареной. Последняя линия редактора — **v05**; старый редактор скрыт из навигации, единственный пользовательский вход — `v05-dynamic.html`.

Данные: **162 карты + 7 токенов = 169 уникальных ID**. Подтверждённый встроенный каталог тестовых артов — **99 ID** (45 CHR, 39 KNZ, 8 NEU, 7 TKN); для **70 карт** собственных изображений пока нет. Арты **тестовые**, а не утверждённые. Они привязаны строго по ID: подмены отсутствующих изображений чужими запрещены. Для KNZ-006/014/019 используется исходный контрольный арт v05. Пользовательский арт имеет преимущество над встроенным.

## 2. Последний выполненный этап v05.11

- Реализован **единый Hero HUD** для 2D и 3D: оружие слева, портрет и здоровье/броня в центре, способность и мана справа.
- 2D перестал уменьшать портрет до 44×47 px на невысоких экранах; предусмотрено компактное правило для 1366×768.
- Слот оружия **виден всегда**. Если оружие есть, он показывает его изображение и числовые атаку/прочность; при прочности 1 предусмотрена предупредительная рамка.
- Способность отображает отдельный значок, стоимость маны и состояние (`ГОТОВА`, `НЕТ МАНЫ`, `ИСПОЛЬЗОВАНА`, `ЗАКРЫТА`, `ВЫБЕРИТЕ ЦЕЛЬ`). Эти состояния читаются из `battle-engine.js`, никакие правила не придуманы.
- 3D получает аналогичный DOM HUD с реальным портретом (`MW_HERO_PORTRAIT_BRIDGE`) и встроенным артом способности (`MW_HERO_ART`), при этом WebGL-герой на поле и боевое взаимодействие остаются прежними.
- В 2D изображение оружия берётся из того же источника, что и большая карта (локальная пользовательская замена > библиотечный арт), без миниатюрной напечатанной карточки.
- Windows `START_WINDOWS.cmd` открывает игру по `http://127.0.0.1:8765/index.html`, а не через `file://`.

## 7. Инструкции по локальному запуску

Windows: распаковать **полный** Windows ZIP в отдельную папку (не накладывать поверх старых файлов). Запустить `START_WINDOWS.cmd`; откроется `http://127.0.0.1:8765/index.html`. Закрыть консоль сервера после окончания. **Один сервер на порт 8765.** Для редактора использовать `START_V05_EDITOR_WINDOWS.cmd`, закрыв первый сервер. Кнопка нового редактора доступна из коллекции. Node **не обязателен** для офлайн-игры; нужен Node 20+ только для отдельной Google Sheets-синхронизации с персонально настроенными переменными окружения.

GitHub Pages: распаковать GitHub ZIP, открыть папку `mythical-wars`, положить **её содержимое** в корень репозитория, включая скрытую `.github`. В Settings → Pages выбрать GitHub Actions, затем запустить `Publish Mythical Wars to GitHub Pages` в Actions. Проверить игру, редактор, 2D и 3D; принудительно обновить кэш (`Ctrl+Shift+R`). Github Pages не выполняет Node backend, запись в Sheets без отдельного защищённого сервера невозможна.

Локальные данные браузера зависят от `scheme://host:port`. `localhost:8765` и `127.0.0.1:8765` — **разные хранилища**; при миграции сначала экспортировать JSON и сохранённые арты.
