## Переполнение автосохранения

На опубликованной версии воспроизведён `QuotaExceededError` для `mw-active-battle-v2.0` после второй тестовой партии. Текущая и резервная партии ранее записывались в общий ограниченный localStorage.

Теперь оба слота записываются в IndexedDB, в отдельные записи meta существующей базы колод. Полный формат партии, повторы, арты, таймер и незавершённый выбор сохраняются. Существующие JSON из localStorage переносятся; исходная копия удаляется только после завершения транзакции и точного совпадения с перенесённой. Другие ключи, колоды и библиотека не удаляются.

Записи выполняются по очереди. Резервный слот получает последнее успешно записанное состояние до создания новой партии. Сообщение об успешном ручном сохранении появляется после завершения транзакции. Ошибка записи сохраняет предыдущие успешные слоты и показывается игроку. При недоступности IndexedDB остаётся прежний резервный способ через localStorage и JSON-экспорт.

## Проверка исправления

- 309 Node-тестов прошли, включая 8 новых проверок миграции, полного localStorage, больших партий, очереди, резервного слота, сбоев транзакции и восстановления после ошибки.
- Проверка исходного сайта: 431 зависимость; проверка собранного Pages: 425 зависимостей.
- Chrome, локальная сборка: реальный localStorage заполнен до QuotaExceededError (39 блоков по 128 КиБ). Успешно перенесены оба старых слота, записана партия 6 МиБ, повторно открыты текущий и резервный слоты с сохранением всех проверяемых полей. Удалены только созданные тестом заполнители.
- В игровом интерфейсе: восстановление боя 15:00 после перезагрузки; новая партия 20:00; следующая партия 21:00; возврат из неё в резервную 20:00 без ошибки сохранения.
