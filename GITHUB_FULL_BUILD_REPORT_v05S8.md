# GitHub Pages, полный проект v05.8 RC

Готовая полная самостоятельная поставка, не отдельные клиентские файлы и не Windows-патч.

- `mythical-wars/index.html` — игровая страница, переход к единственному редактору `v05-dynamic.html`.
- `test-art/` — 92 встроенных WebP плюс инвентарь (ID, sha256, источник, статус).
- `v05/` — исходные слои и маски, оригинальный manifest неизменен.
- `tools/build_pages.py` и `.github/workflows/pages.yml` — раздельный сборщик публичного статического артефакта и деплой.
- `_site/` намеренно **не включается** в репозиторий, поскольку создаётся GitHub Actions при публикации. `v05-studio.html` в публичном `_site/` исключается.
- `server/`, `.env` и служебные ключи не включаются.

Проверки: Node 97/97, Chromium 24/24 + 22/22, статические root 308 и `_site` 302; `ZipFile.testzip()` выполняется перед выдачей. Публичный GitHub Pages и реальное Windows не запускались в текущем окружении.
