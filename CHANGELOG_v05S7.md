# CHANGELOG — v05.7 RC: единый редактор и тестовые арты

Дата: 10.11.2026. Основа: v2.1M.2 + v05.6 RC.

## Изменения

- На главной странице скрыт прежний редактор и сняты все пользовательские переходы в него. Единственная точка входа в редактор — `v05-dynamic.html`. Переходы из коллекции используют `?card=ID`.
- Служебный `v05-studio.html` исключён из GitHub Pages, но сохранён в исходниках для внутренних тестов. Скрытая инфраструктура старого редактора остаётся в `index.html` исключительно из-за существующих зависимостей приложения.
- Добавлена полноценная локальная коллекция тестовых артов `test-art/` и API `mw-test-art-catalog.js`: 92 изображения с точными ID (45 CHR, 39 KNZ, 8 NEU). Эти арты выбираются по умолчанию и в коллекции, и при редактировании, если пользователь не загрузил собственную иллюстрацию.
- Остальные 77 записей без исходного арта показываются как отсутствующие (70 карт + 7 токенов). Ни одно тестовое изображение не получает статус «утверждён».
- Контрольные `KNZ-019`, `KNZ-006`, `KNZ-014` по умолчанию сохраняют исходные v05 art source, а не копии из Google Drive.
- PNG/WebP конверсия не меняет пиксели; копии тестового арта с указанием SHA-256 и статуса в `test_art_inventory.json`.
- Обновлены CI, сборка GitHub Pages, статические проверки SHA-256, документация публикации.

## Не изменялось

Боевой движок, каноническая библиотека, колоды, оригинальные источники артов/слоёв, настройки манифеста v05, ограничения PNG и Google Sheets API. Пользовательские арты и кадрирование имеют приоритет над встроенными.

## Ограничения RC

Нет фактической публикации GitHub Pages; браузерный QA через `about:blank` + реальные Blob-изображения не равен проверке на Windows/HTTPS-домене. Не выполнена проверка сохранения пользовательских PNG после реального перезапуска браузера; серверная Google Sheets авторизация отдельно не подтверждена. Для публичной публикации артов нужны права владельца.
