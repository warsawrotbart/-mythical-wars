## Результат и границы

Подготовлена проверяемая поставка текущего 2D-боя: переходы хода, необязательный таймер, крайние случаи руки, ограниченные по времени визуальные операции и восстановление представления. Проверки ниже выполнены заново на восстановленной копии. Прежние незакоммиченные файлы после отключения машины не сохранились: точная база восстановлена из пакета этапа6, SHA256 которого совпал с MW-LOG-029. Это не окончательная художественная и межплатформенная приёмка всех T14–T20.

Карточный каталог, параметры/тексты/редкости/принадлежность, колоды, исходные арты и production manifest не изменялись. Исправления порядка ядра могут изменить checksum исторических реплеев; прежние коммиты сохраняются.

Таймер хранится в `turnTimer` sidecar JSON, не расходует RNG и не входит в авторитетную игровую механику времени. Включается выбором встречи «Ускоренная ·90с/ход», исходно выключен. Выбор цели/карты тратит время; принятие команды останавливает его на обязательном представлении. Остаток сохраняется каждую секунду и при pagehide/visibility/offline. После загрузки закрытый промежуток не списывается. При offline команды игры отвергаются до online. Автоматическое окончание хода снимает непринятый выбор без оплаты.

`captureCombat` расширен событиями turnStage/clockAdvanced/cardDiscarded/fatigue/creatureReturned. В snapshots нет рук/колод. Для скрытого чужого сброса facade удаляет cardId; лог подгорания не называет чужую скрытую карту. Сброс отделён от кладбища. Возврат с поля пока не подключён к неутверждённой карте.

`battle-motion-runtime.js` ограничивает ресурсы и анимации; `battle-turn-motion.js/.css` выводит короткие баннеры/доступный статус. Старый код руки/боя использует общий lifecycle. Поздний результат загрузки не оживляет отменённый visual; принятая engine-команда не исполняется повторно при reset.
