# v05.11 — Hero HUD (11.11.2026)

- Единый визуальный формат героя, способности и оружия в 2D и 3D.
- Постоянный слот оружия; арт оружия, атака/прочность, предупреждение при 1 прочности.
- Читаемые портреты и отдельные здоровье/броня; стоимость силы в мане вынесена в значок.
- Состояния силы из движка: готова, нет маны, использована, закрыта, выбор цели.
- Браузерное позиционирование 3D-оверлея относительно героя.
- Windows полный офлайн-старт через 127.0.0.1:8765; никаких патчей для установки не требуется.
- 169 ID и 99 тестовых артов; манифест/каталог/движок не менялись.
- Статус RC до реального WebGL/Windows/Pages.
