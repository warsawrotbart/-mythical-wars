# Отчёт QA — v05.11 Hero HUD RC — 11.11.2026

## Основание

Исходник v05.10 восстановлен из полного Windows v05.6 и последовательных патчей v05.8, v05.9, v05.10; GitHub-исходник — полный v05.9 + v05.10. Новые изменения синхронизированы между платформами по SHA-256 для общих исходников.

## Что изменено

- `hero-hud-v05S11.js` / `.css`: новый двухрежимный интерфейс HUD.
- `index.html`: подключение стилей/скрипта после legacy CSS и 3D-модуля.
- `deckgame.js`: визуальный HUD обновляется после гидратации карт (без игрового state-write).
- `arena-3d-v2.1H.js`: группировка экранного Hero HUD на основе проекции героя (WebGL на поле оставлен старым).
- `battle-card-renderer-v2.1C.js`: оружие в слоте показывает иллюстрацию с сохранением приоритета пользовательского арта.
- Windows `START_WINDOWS.cmd`: локальный HTTP-запуск вместо `file://`.

## Что не утверждено

- Реальный GPU WebGL в 3D, скриншот после переключения из 2D, интерфейс на компьютере пользователя.
- Полный Windows E2E (в тестовой среде Linux нет Windows).
- GitHub Pages после реального развёртывания.
- Google service-account JWT + запись в Sheets по Node.
- Изменения в IndexedDB и localStorage после перезапуска Windows.

**Вывод:** v05.11 — самостоятельный **release candidate**, не стабильный релиз.
