# Windows patch v05.10 RC from v05.9

Extract this ZIP **into the existing project folder** containing `index.html`, replacing files. Make a backup first. It is incremental: it requires a functional v05.9 install, including the existing `v05/`, `test-art/` graphics and source layers. It does NOT contain all game assets.

Restart your local server, keep the same host/port (browser storage is origin-specific), then hard reload with Ctrl+Shift+R. Verify mulligan face images, 2D hand and new ribbon title/numbers, followed by 3D: a labelled temporary face must become a finished v05 texture. Real WebGL/Windows testing is pending.

For a brand-new installation, use the full GitHub ZIP or the previous full Windows build plus staged patches, not this incremental patch alone.

No Google private credentials in this patch. Combat rules and approved assets were not edited.
