# GitHub Pages — полная поставка v2.1M.2 + v05.6 RC

Дата сборки: 2026-11-10.

Включено: все 3 HTML-входа (игра, v05-dynamic, v05-studio), клиентский JS/CSS, `assets/`, `v05/` со всеми исходными PNG-слоями, масками и неизменённым production manifest, `arena-art/`, `figma-assets/`, `references/`, `examples/`, 86 клиентских Node-тестов, GitHub Actions CI и ручная публикация Pages.

Из пакета намеренно исключены: `server/` и серверные интеграционные тесты (требуют локального Node backend), JSON-ключи, приватные пользовательские документы/таблицы, Windows `.cmd/.ps1`, временные архивы/логи, больших тестовые скриншоты. Веб-синхронизация Google Sheets требует отдельного HTTPS-сервера и не работает на одном GitHub Pages.

Результаты локальной приёмки пакета:

- `node --test` — **86/86 PASS** (клиентские сценарии; 15 серверных тестов из исходной сборки не входят в публичный репозиторий).
- `tools/check_static_site.py` — **PASS** для корня и отдельно собранного `_site`: 213 проверок HTML/CSS и артов из защищённого v05 manifest.
- Манифест `v05/production/editor_manifest.json` имеет исходный SHA-256 `190371ce21046ba4530b9cb93b374292645218f4fcbe0a0f7e5ff0e529f5529f`.
- `index.html`, `v05-dynamic.html`, `v05-studio.html`, `battle-engine.js`, `card-catalog.js`, `deck-model.js` побайтово совпадают с исходным Windows RC ZIP.
- HTTP-сервер вернул 200 для ключевых страниц/манифеста. Chromium в данной среде блокирует обращения к `127.0.0.1` административной политикой: **реальное открытие страниц по HTTP в Chromium здесь не верифицировано**. Публикация в аккаунт пользователя и браузерная проверка настоящего GitHub Pages также не проводились.

Статус релиза: **RC**, а не окончательно принятый релиз.
