# Мифические войны

Рабочая ветка — **main**. Этапы 2–8 анимаций опубликованы в кодовом снимке `d963b45`; этап 9 — финальная регрессия и приёмка — остаётся открытым. Номер v05.11/v05.16 в старых документах и интерфейсе не определяет текущий Git-коммит.

## Запуск

- [Открыть опубликованную игру](https://warsawrotbart.github.io/-mythical-wars/).
- Windows: после обновления `main` запустите **START_LOCAL.cmd** из корня репозитория. Нужен Python 3.9+. Скрипт распакует 41 ресурс поля, откроет http://127.0.0.1:8000/index.html и запустит локальный сервер. Окно оставьте открытым; остановка — Ctrl+C.
- Для ручного запуска из корня:

```powershell
py -3 tools/unpack_battlefield.py --dest battlefield-v02
py -3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8000/index.html. Двойной щелчок по `index.html` использует `file://`: такой запуск не подходит для проверки составных Canvas-карт. На ПК пользователя переход на HTTP устранил проблему запуска; точная ошибка Canvas отдельно не зафиксирована.

## Обновление и локальные данные

В GitHub Desktop: выбрать `main` → Fetch origin → Pull origin. Это прямое обновление подходит, если нет расходящейся локальной истории. При вручную установленных исторических патчах сначала сохранить локальные изменения и проверить историю; не применять патчи повторно поверх обновлённого main и не делать безусловный reset/force.

Колоды, пользовательские арты и сохранения хранятся в браузере, не в Git. `file://`, `127.0.0.1`, `localhost` и Pages могут использовать разные хранилища. Перед переносом экспортируйте данные; очистка браузерного хранилища не является способом обновления проекта.

## Проверка проекта

Node.js нужен для тестов, Python 3.9+ — для сборки. Из корня:

```sh
node --test
python tools/unpack_battlefield.py --dest battlefield-v02
python tools/check_static_site.py
python tools/build_pages.py
python tools/check_static_site.py --root _site
```

`_site/` и распакованные изображения поля генерируются локально и не коммитятся. Исходный упакованный набор `battlefield-v02/asset_manifest.json` и его chunks сохраняются в Git. Сборка Pages сама распаковывает изображения.
