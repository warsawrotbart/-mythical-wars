# Windows-патч v05.8 — как установить

Патч `MW_v05.8_Builtin_Arts_PATCH_Windows_from_v05.6.zip` содержит набор v05.7 со всеми 92 тестовыми артами **и** новый интерфейс v05.8. Его можно положить поверх полной Windows-сборки **v05.6 RC**: предварительно устанавливать v05.7 отдельно не нужно. Архив содержит относительные пути от корня проекта, папки `test-art/` и `tests/`.

1. Сделайте резервную копию каталога проекта и сохранённых пользовательских данных браузера. Не очищайте IndexedDB: оно содержит пользовательский арт и кадрирование.
2. Распакуйте патч, разрешив замену перечисленных файлов в корне полной сборки v05.6.
3. Запустите редактор через существующий Windows launcher или `http://127.0.0.1:8765/v05-dynamic.html` при работающем локальном сервере.
4. Выберите `CHR-001`, затем `KNZ-001`, `NEU-023`. Справа должен быть встроенный арт, фильтр покажет 92 записи. Для `NCR-001` и `TKN-001` не должна подставляться чужая иллюстрация.
5. Для `CHR-001` загрузите произвольный пользовательский тестовый файл и нажмите «Вернуть встроенный арт». Проверяйте восстановление при повторном открытии карты.

Патч не трогает игровые движки, колоды, манифест v05 и Node-сервер. Google Sheets не синхронизируется автоматически. Полная приёмка Windows остаётся за местным запуском.
